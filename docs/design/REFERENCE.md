# Design Reference

`docs/design/home-reference.png` is the design source of truth for the desktop homepage of `vedishev.ru`.

All further visual changes in P1 and later stages must preserve the same design language:

- light informational header above the main navigation
- split hero with text on the left and portrait area on the right
- trust strip directly below hero
- practice cards with a dark consultation card
- restrained serif plus sans typography
- navy, off-white, graphite, and restrained gold palette
- dark multi-column footer

The goal is not pixel-perfect cloning, but the implemented homepage must remain an obvious production adaptation of this reference rather than drifting back to a generic Payload or Next.js template look.
